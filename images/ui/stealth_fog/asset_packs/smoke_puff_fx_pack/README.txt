Smoke Puff FX Pack - 14 Smoke Sprites
=====================================

14 soft smoke-puff sprites for explosions, dust, fog.

Using these in your engine
--------------------------
Unity: drop PNGs in Assets/. Texture Type = Sprite (2D and UI), Filter = Bilinear, Compression = High Quality. Recolor via the Image component's Color field (art is white = tints to any color).
Unreal: import as Texture2D, Compression = UserInterface2D (RGBA). Multiply by a LinearColor parameter in a UMG Image.
Godot: import as Texture, set as a TextureRect/Sprite2D, set Modulate to recolor.
