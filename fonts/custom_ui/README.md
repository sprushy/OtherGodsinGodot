# Custom UI Font

The active UI test font is Joel Carrouche's `Norsebold.otf`, with `Norse.otf` kept beside it as the regular cut.

`UIFont.gd` uses this face as the default UI font and for Norse card names. The package license is included as `freefont_license.txt`; keep it with the font files.
